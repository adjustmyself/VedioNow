# VideoNow - 影片管理程式

一個功能強大的桌面影片管理程式，支援標籤系統和智慧搜尋，可管理本機硬碟和網路磁碟上的影片檔案。

## 功能特色

### 🎬 影片管理
- 支援多種影片格式（MP4、AVI、MKV、MOV、WMV 等）
- 自動掃描資料夾並建立影片資料庫
- 支援本機硬碟和網路磁碟路徑
- 即時監控資料夾變更

### 🏷️ 標籤系統
- 標籤群組、顏色、說明與說明圖片（標籤管理視窗，可拖曳排序）
- 多標籤篩選搜尋，並顯示目前條件下每個標籤的影片數
- 批次多選：一次為多部影片加 / 移除標籤、評分、刪除記錄
- 自動標籤規則：檔名或路徑符合關鍵字 / 正規表示式時自動加上標籤

### 🔍 智慧搜尋
- 檔名快速搜尋
- 標籤組合篩選
- 進階搜尋功能
- 搜尋結果即時更新

### 📊 檢視與排序
- 網格檢視和列表檢視
- 多種排序方式（建立時間、掃描時間、檔名、檔案大小、影片長度、評分、開啟次數、最近開啟）
- 升序/降序切換
- 儲存常用的搜尋條件，一鍵套用

### 🗂️ 其他
- 影片合集（同資料夾的多部影片合併成一筆）
- 重複檔案偵測、未觀看篩選
- 滑過縮圖顯示多格預覽
- 每日自動備份與還原（SQLite）

### ⭐ 影片詳情
- 影片評分系統
- 自訂描述
- 檔案資訊檢視
- 直接開啟影片檔案

## 系統需求

- Windows 10 或更新版本
- macOS 10.14 或更新版本
- Linux (Ubuntu 18.04 或相容發行版)
- Node.js 16 或更新版本

## 安裝方式

### 開發環境安裝

1. 複製專案
```bash
git clone <repository-url>
cd VideoNow
```

2. 安裝相依套件
```bash
npm install
```

3. 啟動開發模式
```bash
npm run dev
```

### 產品版本建置

```bash
npm run build
```

建置完成後，可執行檔案會在 `dist` 資料夾中。

## 使用方法

### 第一次使用

1. 啟動 VideoNow
2. 點選「掃描資料夾」按鈕
3. 選擇包含影片的資料夾
4. 選擇掃描選項：
   - 包含子資料夾：遞迴掃描所有子目錄
   - 監看此資料夾：記住設定，每次啟動自動更新新增與變更的影片
5. 點選「開始掃描」

### 基本操作

#### 搜尋影片
- 在搜尋框輸入關鍵字可即時搜尋影片檔名與描述
- 點選上方標籤篩選列的群組，再點標籤進行篩選
- 可同時使用關鍵字和標籤篩選

#### 管理標籤
1. 點選影片卡片開啟詳情視窗
2. 從現有標籤點選，或在輸入框輸入新標籤名稱後點選「新增」或按 Enter 鍵
3. 點一下已套用的標籤、再點一次確認即可移除
4. 標籤群組、顏色與說明在「標籤管理」視窗維護

#### 評分和描述
1. 在影片詳情視窗中：
   - 點選星星給予評分（1-5 星）
   - 在描述欄位輸入影片相關資訊
2. 點選「儲存」完成修改

#### 檢視模式
- 點選工具列的「網格檢視」或「列表檢視」切換顯示方式
- 使用排序下拉選單改變排序方式
- 點選排序按鈕切換升序/降序

### 網路磁碟支援

VideoNow 支援 Windows 網路磁碟路徑：
- UNC 路徑：`\\伺服器名稱\共用資料夾`
- 對應的網路磁碟：`Z:\資料夾`

確保：
1. 網路磁碟已正確對應
2. 具有存取權限
3. 網路連線穩定

## 支援的影片格式

- MP4 (.mp4)
- AVI (.avi)
- MKV (.mkv)
- MOV (.mov)
- WMV (.wmv)
- FLV (.flv)
- WebM (.webm)
- M4V (.m4v)
- 3GP (.3gp)
- OGV (.ogv)
- OGG (.ogg)
- MPG/MPEG (.mpg, .mpeg)
- TS (.ts, .mts, .m2ts)

## 資料儲存

- 預設使用 SQLite，資料庫為使用者資料夾（Electron userData，Windows 為 `%APPDATA%\video-now`）下的 `videonow.db`；也可在設定頁改用外部 MongoDB
- 設定檔 `config.json`、縮圖、滑過預覽、標籤圖片與自動備份也都在使用者資料夾；圖片與備份的位置可在設定頁「存放位置」變更
- 不會修改或移動原始影片檔案（除非使用「刪除檔案」或「上傳字幕」）
- 移除或重新安裝程式不會影響影片檔案與使用者資料夾

## 疑難排解

### 常見問題

**Q: 掃描後沒有找到影片**
A: 請確認：
- 資料夾路徑正確
- 資料夾中包含支援的影片格式
- 具有資料夾存取權限

**Q: 網路磁碟無法存取**
A: 請檢查：
- 網路連線是否正常
- 是否具有網路磁碟存取權限
- UNC 路徑格式是否正確

**Q: 程式啟動緩慢**
A: 可能原因：
- 使用 MongoDB 時伺服器連線較慢
- 監看中的資料夾在網路磁碟上，啟動後背景同步需要時間

### 重置程式

如需重置所有資料：
1. 在設定頁「存放位置」開啟資料資料夾
2. 關閉 VideoNow
3. 刪除該資料夾（設定、SQLite 資料庫、縮圖與自動備份都會一併刪除）
4. 重新啟動程式

## 開發資訊

### 技術架構

- **前端**: HTML, CSS, JavaScript
- **後端**: Node.js, Electron
- **資料庫**: SQLite（better-sqlite3，預設）或 MongoDB
- **縮圖 / 預覽**: FFmpeg（隨程式附帶 ffmpeg-static）
- **檔案監控**: Chokidar

### 專案結構

```
VideoNow/
├── src/
│   ├── main.js              # Electron 主程序（IPC、視窗、啟動流程）
│   ├── preload.js           # 畫面端可呼叫的 IPC 白名單
│   ├── database.js          # 資料庫工廠與 MongoDB 實作
│   ├── sqliteDatabase.js    # SQLite 實作
│   ├── videoScanner.js      # 影片掃描與資料夾監看
│   ├── thumbnailGenerator.js# 縮圖與滑過預覽（FFmpeg）
│   ├── backupManager.js     # 備份與還原
│   ├── config.js            # 設定檔讀寫
│   └── renderer/
│       ├── index.html       # 主介面
│       ├── renderer.js      # 前端邏輯（功能模組在 modules/）
│       ├── settings.*       # 設定視窗
│       └── tag-manager.*    # 標籤管理視窗
├── tests/                   # Jest 測試（npm test）
├── dist/                    # 建置輸出
└── package.json             # 專案設定
```

### 開發指令

```bash
npm start          # 啟動產品版本
npm run dev        # 啟動開發模式（含除錯）
npm run build      # 建置可執行檔
npm test           # 執行測試（經由 Electron 的 Node 執行，原生模組才載得起來）
```
